# Don't Drink That!

## English

This repository hosts Windows client downloads and releases for **Don't Drink That!**.

Visit the game on itch.io: [Don't Drink That!](https://tomatofield.itch.io/dont-drink-that).

### Download and play

1. Open the [Releases page](https://github.com/cxdaao/DoNotDrinkThat-Releases/releases) and choose a version. Preview builds are marked **Pre-release**.
2. Download `DoNotDrinkThat-Windows-x64.zip` from the release's **Assets** section.
3. Extract the entire archive, then run `DoNotDrinkThat.exe`. Keep the executable and all bundled files together. For older versions, follow the executable name listed in that release's notes.

### Release files

- `DoNotDrinkThat-Windows-x64.zip`: the portable Windows x64 client.
- `SHA256SUMS.txt`: SHA-256 checksums for the client ZIP and build information file.
- `build-info.json`: version, source commit, build environment, and artifact information.

This repository contains release downloads and documentation. Game source code is maintained separately. Automated build and artifact checks do not constitute manual playtesting.
